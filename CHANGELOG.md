# Changelog

## v0.5 Beta (January 2026)

**Initial beta release** — CashFlow Commander helps you understand and control your money in seconds.

### Features
- 📊 **Dashboard** with financial overview (balance, income, expenses, net flow)
- 🧠 **Smart Insights** powered by AI-driven spending analysis
- 🎯 **Budget Tracking** with progress visualization
- 🏦 **Multiple Accounts** support
- 🎨 **8 Beautiful Themes** (Dark, Light, OLED, Navy, Coral, Emerald Noir, Space Grey, Ultra Blue Nova)
- 🌍 **Multi-language** support (English, Arabic, French, Spanish, German)
- 📱 **Mobile-first** responsive design with bottom navigation
- 🚀 **Onboarding Tour** for new users
